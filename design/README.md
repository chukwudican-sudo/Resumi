# Design

Source for the design canvases. Each directory seeds one published canvas.

- `journey/` — every screen a person walks through, in order. The live one.
- `app/` — the applications-list structure that reframed the product.
- `onboarding/` — the first visual direction pass. Superseded by `journey/`.

The `.dc.html` files are the source of truth; the `.html` next to them is the
seeded output and is regenerated, never hand-edited.

To change a canvas: edit the `.dc.html` files, re-seed, republish to the same URL.

## Direction

Calm and premium. Instrument Serif for headings with italic on the turn of a
sentence, IBM Plex Sans for everything else. Warm off-white ground (#FBFAF8),
near-black bands (#171A18) for rhythm, one accent (#2F5D50) that only ever marks
the single action on a screen.
